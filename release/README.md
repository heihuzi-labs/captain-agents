# 发版用的文件

- `config.json`：更新从哪儿取、发哪几种安装包，只在这一处写。构建流水线和发版流水线都读它。
  - `feeds`：应用按顺序问的清单地址（编进应用）。
  - `hosts`：除清单地址的主机以外，允许连的下载和跳转主机（编进应用）。
  - `publicKey`：更新公钥（编进应用）。对应的私钥在仓库机密 `XA_UPDATE_PRIVATE_KEY` 里。
  - `minimumVersion`：比它旧的应用会被提示手动安装。
  - `targets`：发版时构建并发布哪几种安装包。写在这里的才会进更新清单和发布页。
  - `downloadBases`：安装包的下载前缀，按应用试的顺序写；`{version}` 会换成版本号。
  - `legacyBase`：给 0.2.0、0.2.1 读的旧清单里用的前缀（它们只认发布页）。
- `notes/<版本号>.txt`：这一版的更新说明，纯文字，1–8000 字。应用里的更新提示和发布页正文都用它。发版前必须有。

# 选手联网

主人于 2026-10-09 决定：只保留“能联网 / 不能联网”两种，一个总开关管所有项目，打开后网络完全不限，包括本机端口。

设置放在 `config.json` 的布尔字段 `networkAllowed`，缺省或写坏都按 `false`。只有主人能在桌面应用“设置 → 联网”中修改，桥上走 `setNetworkAllowed`；普通设置补丁、命令行、负责人和选手都不能改。旧的项目 `network` 设置读取时忽略，保存时丢弃。

派活时读取总开关，开着就在任务里记 `network: true`，题目前附联网说明；关着不写该字段。改设置只影响之后派的活。原有隔离自检保留，继续验证关网时的隔离，不再做联网专项自检。

- **Codex**：开着时权限表只加 `network={enabled=true}`，不加 `--enable network_proxy`，不写域名。依据 [2026-10-09 实测](research/worker-network-2026-10-09.md) 第 3.1 节的反例，不开代理时网络全部放开。
- **Grok / Cursor**：关着时仍用原来的 srt 命令行和模板。开着时由小启动脚本 `srt-open.ts` 调 srt 0.0.77 的库接口 `wrapWithSandbox`，传入 `sandbox()` 生成的文件设置，省略网络设置；不调用会起代理的 `initialize`。库按 `allowedDomains` 是否存在决定网络限制，macOS 因此生成 `(allow network*)`，文件规则照旧。依赖位置按已有 `srtPath()` 解析，启动脚本随任务运行时代码一起快照。

文件读写、密钥、登录文件、钥匙串、环境变量规则一条不变；看管进程出错先停止选手的兜底保留。网络开关不改变各家运行必需的登录方式。

风险：打开后选手能连本机服务和外网，主人已知情。

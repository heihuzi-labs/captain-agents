# 登录页加“记住我”

派活工作台会在这份题目前面自动拼上共同规则（`rules.md`）和项目自己的规则，这里不用重复写。

## 要做什么

登录页加一个“记住我”勾选框。勾上后，登录状态保留 30 天；不勾，关掉浏览器就退出。

## 不做什么

- 不改注册、找回密码和第三方登录。
- 不改登录页的样式，只加这一个勾选框，沿用现有表单部件。

## 依据（以代码为准）

- `src/auth/session.ts`：会话怎么建、怎么过期。
- `src/pages/login.tsx`：登录表单。
- `docs/auth.md` 第 2 节：会话有效期的现有约定。

## 交付

- 改 `src/auth/session.ts` 和 `src/pages/login.tsx`，别的文件不动；确实需要改别的，先在报告里说明。
- 补测试：勾选和不勾选两种情况下的过期时间。
- 报告写清：改了什么、为什么这样改、跑了哪些测试和结果、还有什么没把握。

## 注意

- `src/auth/tokens.ts` 是几件活共用的，不许改。
- 先读懂现有会话逻辑再动手；和文档说法不一致时，以代码为准，并在报告里指出。
